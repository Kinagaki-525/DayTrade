# AGENTS.md

このリポジトリは、日本株のデイトレード戦略を記録・検証するためのプロジェクトです。作業時は以下を守ってください。

## 重要ルール

- 実際の証券口座へ注文を送信するコードを追加しない
- SBI証券への自動ログインを実装しない
- SBI証券の画面操作を自動化しない
- `rules/strategy.yaml` の売買ルールを勝手に変更しない
- 売買ルールの改善は提案のみ行い、実変更はユーザー承認後に行う
- 実績データの存在しない結果を生成しない
- バックテスト結果と実取引結果を明確に区別する
- 推測で株価や取引結果を生成しない
- リスク管理ルールを無断で緩和しない
- コード変更時には可能な限りテストを追加・更新する
- 既存テストを壊したまま完了しない
- 計算した注文候補を、実際の約定値や取引結果として `trades/trades.csv` に書き込まない
- `trades/trades.csv` へは、ユーザーが提示した実取引事実だけを記録する

## 実装方針

- まず既存コードと関連ファイルを確認してから変更する
- 必要最小限の変更で目的を達成する
- 不要な大規模リファクタは行わない
- 売買ルールはソースコードへ直接埋め込まず、`rules/strategy.yaml` から読み込む
- 価格計算では浮動小数点ではなく `Decimal` を使う
- 外部APIによる呼値や株価の自動取得は、明示的な依頼があるまで実装しない

## 正本と変更手順

- 売買ルールの正本は `rules/strategy.yaml` とする
- 実取引事実の正本は `trades/trades.csv` とする
- CSV列の意味は `docs/trade-data-dictionary.md` に従う
- 注文計算結果は「候補」であり、注文済み・約定済み・利益見込みとは表現しない
- ユーザー承認後に売買ルールを変更する場合は、`strategy_version` も更新する
- 現行設定と同じ内容を `rules/versions/<strategy_version>.yaml` に保存する
- `rules/versions/` に保存済みの版ファイルは変更・削除しない
- 過去の取引行に記録された `strategy_version` は後から書き換えない
- バックテスト用データを追加する場合は、`trades/trades.csv` と別のファイルまたはディレクトリで管理する
- 変更完了前に `py -B -m pytest` を実行し、結果を報告する
